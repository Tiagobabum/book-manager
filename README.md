Gerenciador de biblioteca pessoal via terminal, com Python e SQLite3. Permite cadastrar usuários e controlar livros e progresso de leitura de cada um, separado por usuários


## Funcionalidades

- Cadastro de usuários
- Cadastro de livros vinculados a cada usuário
- Listagem de livros por usuário
- Controle de progresso de leitura (páginas lidas)

## Tecnologias

- Python
- SQLite3


## Sobre o projeto
Esse é um projeto de estudo, feito para praticar Python e SQLite3. 
Atualmente a interação é feita via terminal (inputs), com planos de evoluir 
para uma interface mais robusta no futuro
